# Included assets

- `ingram-micro-logo.png`: unmodified `Ingram_Micro_Wordmark…_Blue_RGB.png` from the official Ingram Micro brand logo archive, downloaded 2026-10-15. The source artwork is preserved; CSS controls its display size.
  - Brand page: https://www.ingrammicro.com/en-us/company/mediaroom/logos
  - Archive: https://www.ingrammicro.com/Ingram/media/Global-Content/2024/Company/Mediaroom/Logos/Ingram-Micro-Logos.zip
- `xlsx.full.min.js`: SheetJS CE 0.20.3, official standalone build.
  - Source: https://cdn.sheetjs.com/xlsx-0.20.3/package/dist/xlsx.full.min.js
  - License: `SheetJS-LICENSE.txt` (Apache 2.0).

No fonts, logos or spreadsheet libraries are fetched from external sites at runtime. The browser sends lifecycle queries only to the configured Worker; Cisco bulletin links open when the user follows them.
